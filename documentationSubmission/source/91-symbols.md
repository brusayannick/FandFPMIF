L	an event log, a multiset of traces
σ	a trace, an ordered sequence of events
e	an event, minimally (case, activity, timestamp)
c	a case, a process instance
A	the set of activities occurring in L
V	the set of variants of L, the distinct activity sequences in L
|·|	cardinality, e.g. |A| the number of distinct activities
H	entropy of a distribution, used by the complexity measures
p	the p-value of a statistical test
α	the significance level of a statistical test
d	a distance between two logs, e.g. earth mover's distance
n	the number of cases in L
t	a point in time; a window index in the over-time modules
